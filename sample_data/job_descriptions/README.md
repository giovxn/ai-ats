# Sample job descriptions

All companies are fictional. Each file is a different way real job ads are written.

| File | Format | What it tests |
|---|---|---|
| `senior_accountant.txt` | Classic structured ad: about, responsibilities, "Requirements" and "Nice to have" lists | The baseline; the must-have / nice-to-have split is explicit |
| `full_stack_engineer.txt` | Startup ad: "What you'll do", "What we're looking for", "Nice to have" | Tech stack with alternatives ("FastAPI, Django or Flask") and "preferred" inside a must-have line |
| `account_executive.txt` | Short prose, no lists | Must-haves ("You must", "at least 3 years") and nice-to-haves ("It's a plus if") written as sentences; "we use HubSpot" is context, not a requirement |
| `operations_manager_prose.txt` | All prose, no bullets, plus salary, benefits and an equal-opportunity and privacy footer | Requirements hidden in sentences ("at least five years", "would be a real advantage", "helps but is not essential"); the footer and benefits must not become requirements |
| `sales_executive_agency_post.txt` | Gulf recruitment-agency post: capitals, asterisks, urgent tone, email-your-CV | Discriminatory criteria (gender, age, nationality). They must be flagged under "Not used for screening", never extracted as requirements |
